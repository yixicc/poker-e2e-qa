## 页面结构

三个 Tab：健康概览 / 模型评价 / 报告查询。

模型评价再拆：总览、调用落点、模型表现、失败定位、内容得分、报告明细、调用账本。

评价页顶部可筛：全部 / 场次 / 位置 / 对手 / 首页。

## 三套口径（接手后不要混着改）

1. **份**：生成任务。总览三个指标、按业务报告。全部约 707 份。
2. **次**：模型请求（含写稿、审核、重试、修订）。模型表现、调用质量。全部约 7676 次任务 / 8146 次请求。
3. **打分次数**：评审打的每一轮。内容通过率 188/1149。

筛「场次」时，总览调用成功率走调用落点样本（约 824），模型表现走全量调用账（约 4350），现在对不上。过线 188/707 的分子含混跑写稿，分母是当前策略任务，也不齐。
