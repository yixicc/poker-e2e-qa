# 指标用例 · 共用样例场

主卡里的数字都按这些场手算。换了素材，先改本场清单再改期望。

## 场A · 用户参与（Session / 盈亏默认场）

用户作为 Hero 入座的德州录像。播放器时长 **12:30（750 秒）**。6 人桌。切出 **8 手唯一牌**。另把 H1 再切一刀（同一 `hand_id`），不得把总手数加成 9。

| 手 | 位置 | 做什么 | 参与 | 翻前弃 | 进翻后 | 摊牌 | chips | 大盲 | BB |
|---|---|---|---|---|---|---|---|---|---|
| H1 | CO | 自愿 raise，进翻后，亮牌赢 | 是 | 否 | 是 | 是 | +200 | 100 | +2.0 |
| H2 | BTN | 自愿 limp，进翻后，对手弃未亮 | 是 | 否 | 是 | 否 | +100 | 100 | +1.0 |
| H3 | BB | 被加后 call 防守，进翻后，亮牌输 | 是 | 否 | 是 | 是 | −150 | 100 | −1.5 |
| H4 | BB | 只交盲即 fold（无再加码） | 是* | 是 | 否 | 否 | −50 | 100 | −0.5 |
| H5 | UTG | 翻前 fold，无盲无盈亏 | 否 | 是 | 否 | 否 | 0 | 100 | 0 |
| H6 | CO | 自愿 raise，进翻后，未摊牌赢 | 是 | 否 | 是 | 否 | +80 | 200 | +0.4 |
| H7 | BTN | 翻前 fold | 否 | 是 | 否 | 否 | 0 | 200 | 0 |
| H8 | HJ | 自愿 call，进翻后，亮牌输 | 是 | 否 | 是 | 是 | −300 | 200 | −1.5 |

\*H4 按清单「产生盈亏即计入」算参与。产品若确认只交盲不算，改参与=5、相关比率一并改。

手算汇总：

- 总手数 8
- 参与 6（H1 H2 H3 H4 H6 H8）
- 翻前弃 3（H4 H5 H7）
- 进翻后 5（H1 H2 H3 H6 H8）
- 摊牌 3（H1 H3 H8）
- 自愿入池 VPIP 5（H1 H2 H3 H6 H8；H4 只交盲不算自愿）
- PFR 2（H1 H6）
- 盈亏筹码 −120；BB −0.1（按手大盲换算再加总，不是 −120÷场均盲）
- 赢 3 / 亏 3 / 平 2

## 场B · 围观

用户只围观 20 分钟，自己未入座、无 Hero 手牌。不得当作用户本场战绩。

## 场C · 无关

大厅闲聊或其他游戏，约 5 分钟。不得生成德州 Session。

## 场D · GTO 决策点（10 个点）

| 点 | 实际 | GTO | 归类 |
|---|---|---|---|
| D1 | raise 3bb | 主推 raise 2.5bb（尺度 +20%，在 ±30% 内） | 符合 GTO |
| D2 | call | 主推 fold 80%，call 25%（<30%） | 风险偏高 |
| D3 | call | 主推 raise 60%，call 35%（>30%） | 基本可接受 |
| D4 | raise 5bb | 主推 raise 2.5bb（尺度超出 ±30%） | 基本可接受 |
| D5 | fold | 主推 fold 90% | 符合 GTO |
| D6 | raise | 无 GTO 返回 | 信息不足 |
| D7 | 看不清动作 | 有推荐 | 信息不足 |
| D8 | bet | 主推 check 80%，bet 15% | 风险偏高 |
| D9 | check | 主推 check 70% | 符合 GTO |
| D10 | all-in | 主推 all-in 40% | 符合 GTO |

- 总决策点 10；信息不足 2；可判断 8
- 符合 4（D1 D5 D9 D10）；可接受 2（D3 D4）；高风险 2（D2 D8）
- 匹配度 4/8=50%；可接受占比 (4+2)/8=75%；高风险 2/8=25%

## 场E · 机会分母（打法率）

同一场用户参与，专门凑齐「做了 / 有机会没做」：

- 可 limp 4 次：limp 1、raise 2、fold 1 → limp_rate=1/4
- 面对 open 4 次：call 1、3bet 1、fold 2 → call_open=1/4，three_bet=1/4
- 面对 3bet 3 次：4bet 1、fold 1、call 1 → four_bet=1/3，fold_to_3bet=1/3
- BB 被加 3 次：call 1、raise 1、fold 1 → bb_defense=2/3
- SB 被加 2 次：fold 2 → sb_defense=0/2=0%（有分母，可以是 0%）
- 可 c-bet 3 次：flop bet 2、check 1 → cbet=2/3
- 翻牌已 bet 后可转牌继续 2 次：转牌 bet 1、check 1 → turn_barrel=1/2
- 河牌可行动 3 次：bet 1、check 2 → river_bet=1/3
- 河牌被加 2 次：call 1、fold 1 → river_call_vs_raise=1/2
- 翻后面对下注 5 次：call 2、raise 1、fold 2 → postflop_call=2/5，postflop_raise=1/5

另备一场：用户参与了 8 手，但从未面对 open / 从未可 limp（用来测分母为 0，见边界表）。

## 场F · 位置名

- 2 人桌 1 手：位置只能是 BTN / SB / BB 这套，不能出现 UTG
- 6 人桌用场A
- 9 人桌 1 手 Hero 在 UTG+2

## 场G · 对手

- 玩家甲：与 Hero 共同入池 3 手，Hero 对甲筹码 +80、+20、−40，合计 +60
- 玩家乙：共同入池 1 手，Hero −100
- 同桌但未共同入池 2 手：不得记入交手/对对手盈亏
- 昵称：甲=「小王」，乙看不清（乙的 name 省略，不得编「玩家2」）

## 场H · 白名单（06 定义）

- 弱顶对继续：A 高面 Hero A7（算）、ATs（不算）；转河继续投入 1 次 / 弱顶对场景 2 次 → 1/2
- 边缘入池：54s 入池、A2o 入池、AA 入池（AA 不算边缘）；边缘牌 fold 1 次只进分母
- 弱 A/K：A5 入池计 1；AT 入池不计
- 边缘连张：54s 入池计 1；JTs 入池不计
- 不利位置边缘：UTG 54s 入池计 1；BTN 54s 入池不计

## 场J · 摊牌可发生在任意街

摊牌只看亮牌 / showdown 标记，不看「是不是河牌才下注」。

| 手 | 在哪一街形成摊牌条件 | 亮牌 | 计入摊牌 |
|---|---|---|---|
| J1 | 翻前 all-in 且有人跟，翻前亮牌，再发翻/转/河 | 是 | 是 |
| J2 | 翻牌 all-in 且有人跟，翻牌亮牌，再发转/河 | 是 | 是 |
| J3 | 转牌 all-in 且有人跟，转牌亮牌，再发河 | 是 | 是 |
| J4 | 河牌 bet/call，河牌亮牌 | 是 | 是 |
| J5 | 三人翻前 all-in 且跟到底，翻前亮牌 | 是 | 是（只 +1 手） |
| J6 | 翻前 all-in，无人跟，不发翻/转/河，翻前收池不亮 | 否 | 否 |
| J7 | 翻牌有人弃牌结束 | 否 | 否 |
| J8 | 转牌有人弃牌结束 | 否 | 否 |
| J9 | 河牌对手弃牌，Hero 未亮收池 | 否 | 否 |

正例合计 5 手，反例 4 手。J1 同时算进入翻后，不算翻前弃牌。

## 场I · 时间序 / 心态

12 手按时间排列，单手盈亏符号：

`+ + + − 0 + + − − − + −`

- 最长连赢 3（开头）；最长连亏 3（第 8–10 手）
- 打平打断连赢/连亏
- 前/中/后各 4 手算分段 VPIP（前 4 手入池 1，中 4 手入池 3，后 4 手入池 2）
