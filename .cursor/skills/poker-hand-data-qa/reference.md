# 牌局数据问题清单与口径

配合主流程 [SKILL.md](SKILL.md)。只在扫到对应层时读本文件。

## 金额

- **增量**（`auto_json.actions`）：`amount` = 这一口新推进去的筹码。小盲 5、大盲 10 时，下一手最小加注增量是 10。
- **累计**（`actionSequence`）：`amount` = 该玩家本街已投入合计。跟注到 1020 表示本街总投入 1020，不是又加 1020。
- 同街出现多次动作时（如 CALL 后又 FOLD），**取本街最大 amount**，不要取最后一条（fold 常记 0，会吞掉已投入）。
- 盲注/Straddle 若不在动作里，算投入时要补上。Ante = 人数 × `ante`。
- **交叉验证盲注**：某玩家 `initChips − finalChips` 与动作投入不符时，先怀疑动作序列漏记盲注/前注（如 BB fold 记 0 但实际已投 BB）。

未跟注与边池拆分算法见下方「底池拆分与未跟注返还」。

## 底池拆分与未跟注返还

### 一、未跟注返还（uncalled bet）

最后一条街：最高累计投入 > 第二高累计投入，差额就是未跟注，应**返还给投入最高者**，不进 `total_pot`。

- 只有**一轮**未跟注要扣，即「本街最高投入 − 本街第二高投入」这个差额。
- 多路 all-in 时同样适用：最高档超出第二档的部分返还。

### 二、多路 all-in 边池拆分算法

n 人 all-in、金额不等时，把每人本街（或全局累计）投入**从小到大排序去重**为 `v1 < v2 < ... < vk`，令 `v0 = 0`：

```
第 i 档底池金额 = (vi − v(i-1)) × (投入 ≥ vi 的人数)
pots[i].players = 投入 ≥ vi 且未弃牌的所有人
winners ⊆ pots[i].players
```

- 主池 = 第 1 档，边池依次为第 2、3…档。
- 最高档若只有 1 人达到（即投入最高者独高），该档即未跟注，返还给那人，不构成底池。

### 三、示例

三人翻前 all-in：P0=100，P1=200，P2=300，无人弃牌：
- 排序去重：100, 200, 300
- 档1 = 100×3 = 300，players=[P0,P1,P2]（主池）
- 档2 = (200-100)×2 = 200，players=[P1,P2]
- 档3 = (300-200)×1 = 100，只有 P2 独高 → **未跟注，返还 P2**
- `total_pot` = 300 + 200 = 500（P2 只进账 200 而非 300）

收池无人摊牌时 `pots.players` 只写赢家；边池只写参与那一档的人，不要写全桌。

## `pots.players`

写「能赢这一层的人」。写对的样本：收池 `["P7"]`；摊牌 `["P0","P4"]`；边池只写多出来那一层。

## 非真实错误（不报 / 单独标注）

1. **INIT_CHAIN**：相邻手同名玩家 `initChips` ≠ 上手 `finalChips` → 多为买入 / 离桌 / 重坐，不是单手结算错误。
2. **OCR_POT_SCREEN**：OCR 底池 max > `total_pot` → 多为屏幕含未跟注下注，不以 OCR 为终池。
3. **OCR_BOARD 偶发误读**：未按 Hero 手牌过滤时易混入邻手帧。
4. **翻前结束但末帧有公共牌**：常为下一手污染。
5. **边池手用「整池−投入」验所有 winners**：会误报，应逐档验。
6. **Excel 把 `1/2`、`5/10` 显示成日期**：显示问题，不是牌局错误。

## 分层问题目录

**表 / Excel：** 大小盲显示成日期；造边池却标边池=否；用例名 / 位置列 / 动作摘要 / JSON 不是同一手。

**德州规则：** 加注低于最小加注；轮次结束后仍行动；未结束就进下一街（大盲期权被跳过）；无人下注写成 raise；RAISE 未抬高水位（实为 call）；Straddle 第一手不是其左手。

**底池 / 结算：** 投入 ≠ `total_pot`；缺 `result`（缺 showdown/winners/total_pot/pots）；fold 进了 `showdown_players`；`pots.players` 写成全桌；`sum(pots.amount) ≠ total_pot`；把净赢当池额（如 1380 是净赢，底池应为 2430；pots.amount 写 990 实为净赢）；Turn/River 未跟注下注没退回（对手 fold 后 BET 金额仍被加进终池）；OCR 底池（含未跟注下注）直接当 `total_pot`。

**静态字段：** 手牌与板面重复；缺 `finalChips`；全桌 `Σ(finalChips − initChips) ≠ 0`（含 ante）；`10C` 与 `TC` 混用；错用邻手牌面（如 #11 曾用 #10 的板面）；翻前结束但末帧有公共牌（下一手污染）；边池手用「整池−投入」验所有 winners 会误报。
